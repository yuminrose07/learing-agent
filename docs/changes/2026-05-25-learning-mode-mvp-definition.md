# 2026-05-25 学习模式一阶段 MVP 定义稿

## 范围

新增一份学习模式一阶段 MVP 定义稿，用于回答：

- 现阶段学习模式到底应该证明什么价值
- 一阶段的主场景、主路径、必做功能是什么
- 哪些内容应明确延后，避免模式继续失焦

## 变更内容

- 一阶段产品目标与非目标
- 目标用户与唯一主场景

- 一阶段用户流程与 4 个必做产品件

- 成功指标、失败信号、验收标准
- 产品优先级与下一步建议

## 设计结论

- 学习模式一阶段不应追求完整，而应先证明“学一个明确主题时，它明显比 Chat 更有用”。
- 一阶段应收敛为“单主题学习闭环”，而不是长期学习系统总入口。
- MVP 必须包含明确的结束验收动作，否则学习模式仍会退化成更长的聊天。
